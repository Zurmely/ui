# toast

## Labels

The title is the outcome. Write "Saved".

## Buttons

Action is a short verb: "Undo". Close is "Dismiss".

## Empty states

Toast has no empty state.

## Errors

Do not put a blocking error in a toast. Use Alert or Dialog.

A toast can confirm a failure that does not block work: "Save failed. Try again."

## Helper text

Write one supporting fact in the description. Example: "Profile saved."
