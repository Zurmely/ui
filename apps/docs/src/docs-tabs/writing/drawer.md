# drawer

## Labels

Name the panel in the title. Write "Settings" or "Filters".

## Buttons

Footer actions follow Button rules.

Close can be "Done" when the drawer saves as the user edits.

## Empty states

Drawer has no empty-state slot. If a list in the drawer has no items, write that in the body.

## Errors

Put field errors on Field inside the drawer.

## Helper text

Use one line of context in the description. Example: "Manage your preferences."
