# radial-progress

## Labels

Name the task. Write "Upload complete". Do not leave the default "Progress" if the context is not clear.

## Buttons

RadialProgress has no buttons.

## Empty states

RadialProgress is not an empty state.

## Errors

RadialProgress does not show errors. Put a failure on Alert or Toast.

## Helper text

RadialProgress has no helper text. Nearby text can show percent if the product needs it.
