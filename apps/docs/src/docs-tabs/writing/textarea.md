# textarea

## Labels

The visible label names the data. Write "Bio" or "Description". Do not use placeholder as the only label.

## Buttons

Textarea has no buttons.

## Empty states

An empty field is the default. Textarea has no empty-state message.

## Errors

Put the message on FieldError. Be specific: "Enter a description."

## Helper text

Placeholder can show an example of tone or length. Put limits on FieldDescription.
