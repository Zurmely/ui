# breadcrumbs

## Labels

Name each crumb with the page title. The last crumb is the current page.

Change the nav name from "Breadcrumb" only when the trail needs a clearer name.

## Buttons

Breadcrumbs are links, not action buttons. Do not write "Go back".

## Empty states

Breadcrumbs have no empty state.

## Errors

Breadcrumbs do not show errors.

## Helper text

Breadcrumbs have no helper text.
