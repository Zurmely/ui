# text-field

## Labels

The visible label names the data. Write "Email". Do not use placeholder as the only label.

## Buttons

TextField has no buttons.

## Empty states

An empty field is the default. TextField has no empty-state message.

## Errors

Put the message on FieldError. Be specific: "Enter a valid email."

## Helper text

Placeholder can show an example: "you@example.com". Put longer rules on FieldDescription.
