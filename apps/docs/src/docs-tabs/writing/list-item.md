# list-item

## Labels

The label is the row name. Write "Notifications". For a nav row, use the page name.

## Buttons

If the row is a button, the label is the action. Do not put a second action word in the description.

## Empty states

ListItem has no empty-state slot. Put "no items" copy on the page around the list.

## Errors

When the row wraps a control, put the error on Field or on the row description.

## Helper text

Write one short fact in the description. Example: "Email and push alerts".
