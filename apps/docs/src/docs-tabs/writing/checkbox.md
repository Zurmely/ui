# checkbox

## Labels

State the choice in the positive. Write "Email me about releases". Do not write "Check this box".

## Buttons

Checkbox is not a button.

## Empty states

Checkbox has no empty state.

## Errors

Put the error on FieldError. Say what the user must accept, for example "Accept the terms to continue".

## Helper text

Put extra conditions on FieldDescription, not in the label.
