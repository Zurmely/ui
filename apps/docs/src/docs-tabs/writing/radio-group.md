# radio-group

## Labels

Name the group. Write "Plan". Name each option as the choice: "Free" or "Pro". Do not write "Select one".

## Buttons

Radio items are not action buttons.

## Empty states

RadioGroup has no empty state. Always show a visible option set.

## Errors

Put the error on FieldError. Write "Choose a plan."

## Helper text

Put extra cost or limit notes on FieldDescription.
