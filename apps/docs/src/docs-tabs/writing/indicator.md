# indicator

## Labels

Badge text is a count or a short mark. Write "12" or "New".

For a dot, the name states the state: "Online" or "New notifications".

## Buttons

Indicator has no buttons.

## Empty states

Do not show the indicator when the count is zero, unless zero is meaningful.

## Errors

Indicator is not an error message.

## Helper text

Indicator has no helper text.
