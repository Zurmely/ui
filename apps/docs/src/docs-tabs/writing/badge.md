# badge

## Labels

Use one word or a short count. Write "Active" or "3". Do not write a sentence.

## Buttons

Badge is not a button. Do not put actions in a badge.

## Empty states

Badge has no empty state. Do not show a badge when there is no status to show.

## Errors

Do not use a badge as an error message. Use Alert or FieldError.

## Helper text

Badge has no helper text. Nearby text must carry the meaning.
