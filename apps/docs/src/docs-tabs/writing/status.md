# status

## Labels

Write the operational state: "Online", "Degraded", or "Error". Do not rely on the dot color alone.

## Buttons

Status has no buttons.

## Empty states

Status has no empty state. Do not show it when there is no state to show.

## Errors

A danger label can say "Error" or "Offline". Put the explanation on Alert or nearby text.

## Helper text

Status has no helper text.
