# select

## Labels

Name the field. Write "Country". Option text is the value the user chooses.

## Buttons

Select is not a button. Do not write "Select" on the trigger.

## Empty states

Placeholder is the empty prompt. Write "Choose a country". Do not use the placeholder as the only label.

## Errors

If the field needs a value, write "Choose an option" on FieldError.

## Helper text

Put extra limits on FieldDescription.
