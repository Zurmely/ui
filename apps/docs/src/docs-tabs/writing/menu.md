# menu

## Labels

Name the set of actions on the trigger. Write "Options" or the object name.

Each item names one action: "Edit", "Duplicate", or "Delete".

## Buttons

Menu items are commands. Use verbs. Put a destructive item last. Name the object when the risk is high.

## Empty states

Menu has no empty state. Do not open a menu with no items.

## Errors

Menu does not show errors.

## Helper text

Menu has no helper text.
