# calendar

## Labels

Name the field, for example "Birthday" or "Start date".

Calendar shows month names and weekday names.

## Buttons

Day cells show dates. Keep "Previous month" and "Next month" unless the product language needs a change.

## Empty states

Calendar has no empty-state message. An unselected date is the default.

## Errors

Put the validation message on FieldError. Do not write the error on the grid.

## Helper text

Put date format or range hints on FieldDescription.
