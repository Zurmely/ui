# filter

## Labels

Name the group, for example "Status" or "Tags".

Chip text is the filter value. Write "Design", not "Filter by design".

## Buttons

Filter chips are not action buttons. Do not write "Apply" on a chip.

## Empty states

Filter has no empty state. Do not show a chip that has no meaning.

## Errors

Filter does not show errors.

## Helper text

Filter has no helper text.
