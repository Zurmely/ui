# card

## Labels

Name the unit in the title. Write "Pro plan", not "Card".

## Buttons

Footer actions follow Button rules. Name the action, not "Submit".

## Empty states

Card has no empty-state slot. If the card has no data, write that in the body.

## Errors

Card does not show field errors. Put those on Field inside the card.

## Helper text

Write short supporting copy in the description. Example: "Billed monthly".
