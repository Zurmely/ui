# rating

## Labels

Write the question the stars answer. Example: "How was your experience?"

## Buttons

Rating has no buttons. Do not add Submit on the stars.

## Empty states

A zero value is not an empty-state message.

## Errors

If the field needs a rating, write "Choose a rating" on FieldError.

## Helper text

Put scale meaning on FieldDescription. Write "1 is poor. 5 is excellent."
