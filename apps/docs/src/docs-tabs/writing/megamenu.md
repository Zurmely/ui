# megamenu

## Labels

Name the category on the trigger. Write "Products". Item text names the destination.

## Buttons

Megamenu items are navigation, not actions. Do not write "Open" on the trigger if the category name is enough.

## Empty states

Megamenu has no empty state. Do not open a panel with no links.

## Errors

Megamenu does not show errors.

## Helper text

Megamenu has no helper text.
