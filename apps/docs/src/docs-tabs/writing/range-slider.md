# range-slider

## Labels

Name the value. Write "Price" or "Volume".

In range mode, the thumbs are "Minimum value" and "Maximum value".

## Buttons

RangeSlider has no buttons.

## Empty states

RangeSlider has no empty state.

## Errors

Put out-of-range copy on FieldError.

## Helper text

State units on FieldDescription. Write "USD" or "Percent".
