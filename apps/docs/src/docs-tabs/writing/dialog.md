# dialog

## Labels

Name the task in the title. Example: "Delete project".

## Buttons

Confirm names the action: "Delete". Cancel is "Cancel". Do not use "OK" for a destructive action.

## Empty states

Dialog has no empty state.

## Errors

If the dialog reports a failure, put the failure in the title or the description.

## Helper text

State the consequence in the description. Example: "This action cannot be undone."
