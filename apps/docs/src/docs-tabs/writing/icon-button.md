# icon-button

## Labels

The accessible name is the label. Name the action: "Close", "Edit", or "Delete". Do not name the icon.

## Buttons

There is no visible button text. If the action is destructive, name the object: "Delete comment".

## Empty states

IconButton has no empty state.

## Errors

IconButton does not show errors.

## Helper text

IconButton has no helper text. A tooltip can repeat the same name, not a new instruction.
