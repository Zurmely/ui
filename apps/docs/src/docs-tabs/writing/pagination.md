# pagination

## Labels

The region default name is "Pagination". Numbered links use the page number.

Give previous and next an accessible name: "Previous page" and "Next page".

## Buttons

Previous and next are links. Visible text can be "Previous" and "Next". Do not use only icons without those names.

## Empty states

Pagination has no empty state. Do not show pagination when there is one page.

## Errors

Pagination does not show errors.

## Helper text

Pagination has no helper text.
