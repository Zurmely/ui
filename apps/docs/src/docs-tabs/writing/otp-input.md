# otp-input

## Labels

Name the code. Write "Verification code". Do not number the digits in the label.

## Buttons

OTPInput has no buttons.

## Empty states

OTPInput has no empty-state message. Empty digits are the default.

## Errors

Put failures on FieldError. Write "The code is incorrect" or "The code expired".

## Helper text

State where the product sent the code. Example: "Enter the 6-digit code we sent to your email."
