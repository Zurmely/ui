# steps

## Labels

Change "Progress" when the flow needs a clearer name. Each step title is a stage: "Account" or "Profile".

## Buttons

Steps has no buttons. Put Continue and Back in the step panel.

## Empty states

Steps has no empty state.

## Errors

Steps does not show step errors. Put those in the active panel.

## Helper text

Write one short outcome in the step description. Example: "Create your account".
