# button

## Labels

The label is the action. Write a verb: "Save", "Delete", or "Continue".

## Buttons

Name the main action on the primary button.

For a danger action, name the object when the risk is high: "Delete project".

During load, keep the same verb or write the in-progress form: "Saving".

## Empty states

Button has no empty state.

## Errors

Button does not show errors. Put errors on Field or Alert.

## Helper text

Button has no helper text.
