# file-input

## Labels

Name the file the user uploads. Write "Resume" or "Profile photo".

## Buttons

Default browse text is "browse". After the user chooses a file, the control shows "Change files". Keep those words short.

## Empty states

Empty dropzone copy tells the user what to do. Default is "Drag and drop files here, or browse".

## Errors

Put type and size failures on FieldError. Example: "Upload a PDF."

## Helper text

Put allowed types on FieldDescription. Do not hide the rule only in the dropzone.
