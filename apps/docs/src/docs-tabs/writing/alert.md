# alert

## Labels

Name the event in the title. Write "Saved", not "Success".

## Buttons

Write action text as a short verb. Use "Retry" or "Undo".

## Empty states

Alert is not an empty state. Put "no results" copy on the page.

## Errors

For a danger alert, say what failed and what the user can do. Do not write "Error" alone.

## Helper text

Use the description to support the title. Do not repeat the title.
