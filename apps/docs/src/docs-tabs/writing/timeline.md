# timeline

## Labels

Name the list when the purpose is not clear. Example: "Release history".

Each item has a date, a title, and an optional description.

## Buttons

Timeline has no buttons.

## Empty states

Timeline has no empty-state slot. Put "No activity yet" on the page when the list is empty.

## Errors

Timeline does not show errors.

## Helper text

Write one or two short facts about the event in the description.
