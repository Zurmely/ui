# tabs

## Labels

Each tab names the view. Write "Account" or "Security". Use the same words in the panel heading if there is one.

## Buttons

Tabs are not actions. Do not write "View account" on a tab.

## Empty states

Tabs has no empty-state slot. If a panel has no data, write the empty copy in that panel.

## Errors

Tabs does not show errors.

## Helper text

Tabs has no helper text.
